---
title: web_fetch - Web Fetch
description: Fetch web pages and document content
---

Fetch the content of an HTTP/HTTPS URL. Web pages are extracted as readable text; document files (PDF, Word, Excel, etc.) are downloaded and parsed automatically.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `url` | string | Yes | HTTP/HTTPS URL (web page or document) |
| `provider` | string | No | `local` (default) or `lexmount`; documents always use the local parser |

## Supported file types

| Type | Formats |
| --- | --- |
| PDF | `.pdf` |
| Word | `.docx` |
| Text | `.txt`, `.md`, `.csv`, `.log` |
| Spreadsheet | `.xls`, `.xlsx` |
| Presentation | `.ppt`, `.pptx` |

## Use cases

- Extract readable text from a web page
- Download and parse remote documents
- Inspect API response bodies

<Note>
  The default `local` provider retrieves static HTML. Use the `lexmount`
  provider for rendered public pages, or the `browser` tool when clicks,
  login state, forms, screenshots, or downloads are required.
</Note>

## Lexmount WebFetch provider

Lexmount WebFetch renders public webpages and returns structured readable
content. Configure `LEXMOUNT_API_KEY` and `LEXMOUNT_PROJECT_ID`, then set:

```json
{
  "tools": {
    "web_fetch": {
      "provider": "lexmount"
    }
  }
}
```

You can also select `provider: "lexmount"` for one call. PDF, Word, Excel,
and presentation files keep using CowAgent's local parsers. Lexmount currently
documents WebFetch API as internal testing; confirm access before production use.
